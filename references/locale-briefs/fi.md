## Address and gender

- `sinä` throughout app-owned copy: second-person singular verbs, the possessive suffix `-si` where ownership is not already obvious, never the polite plural. Apple's Finnish does the same on the exact screens this app mirrors: "%@ haluaa lähettää sinulle ilmoituksia" (`System/Library/PrivateFrameworks/UserNotificationsServer.framework | Localizable.strings | USER_NOTIFICATION_PERMISSION_ALERT_TITLE`), "nähdä aktiivisuustietosi" (`Applications/FamilyControlsAuthenticationUI.app | Localizable.strings | NOTIFICATION_AUTH_REQUEST_MESSAGE_INDIVIDUAL`), "Voit laittaa terveysdatakategoriat päälle myöhemmin Terveys-apissa." (`System/Library/PrivateFrameworks/HealthUI.framework | HealthUI-Localizable.strings | AUTHORIZATION_DONT_ALLOW_ALERT_MESSAGE`); Apple's own Finnish iPhone guide addresses the reader the same way ("Avaa Asetukset ja napauta…", https://support.apple.com/fi-fi/guide/iphone/iph7f15d92dd/16.0/ios/16.0, fetched 2026-09-16). This is not an open decision: unlike a T/V language, Finnish consumer software has one register here and Apple, the system alerts the app mocks, and the app's own voice all sit in it.
- Controls are second-person singular imperatives, including the negative imperative: "Salli" / "Älä salli" / "Jatka" (`UserNotificationsServer.framework | Localizable.strings | PERMISSION_ALERT_ALLOW`, `PERMISSION_ALERT_DENY`; `Applications/FamilyControlsAuthenticationUI.app | Localizable.strings | COMMON_CONTINUE`).
- The app speaks about itself in the first person plural on 19 `en` keys ("We couldn't load the data.", `component.errorView.message`; "we'll use %@", `onboarding.hourlyWage.footer`; "We covered %@ with a streak freeze.", `streakFreeze.usedBody`). No Apple Finnish citation anywhere in this section uses a first-person-plural voice — every one is `sinä` — so Finnish states the fact plainly rather than adopting an unevidenced corporate "we": "Tietojen lataus epäonnistui.", "Tuntihinnaksi tulee %@.", "Jäädytys kattoi %@." (naming the freeze as the actor, the same construction `## Header and label forms` already uses for `widgets.streak.copy.frozen.small`). Do not turn these into a passiivi that hides who acted.
- Gender: Finnish has no grammatical gender. Adjectives, participles and predicate nouns do not agree with the reader's gender, and the third person pronoun `hän` is the same for everyone, so this locale needs no neutral strategy and the `ro` gender hotspots disappear. The `en` keys that force a gendered form in `ro` carry none in Finnish: `achievements.streak.body` ("You showed up %lld days in a row." -> "Olit paikalla %lld päivää peräkkäin."), `achievements.badge.fullDaysFifty.earned`, `achievements.badge.hired.name`, `achievements.badge.salaried.name`, `achievements.badge.rehired.name`, `achievements.badge.clockedIn.earned`, `achievements.gauge.title`, `widgets.tasks.allDone`. Reader predicates behave the same way: `focusTask.alert.deleteTask.message` ("Are you sure…"), `onboarding.dailyFocusGoal.subtitle`, `screenTime.createRestrictedList.savedMessage`, `shield.reflection.begin.title`.
- What does need agreement is number and case, not gender: a participle labelling a noun matches that noun ("%lld appi estetty" / "%lld appia estetty", `screenTime.restrictedApps.appsRestricted`), and a fragment with no visible noun needs the noun named rather than a bare participle (`## Header and label forms`).
- The only reader-gender surface left is the picker itself, four plain nouns: `user.gender.female`, `.male`, `.other`, `.preferNotToSay`. The stored profile gender (`Manifesting/Features/User/Domain/Entities/Gender.swift`) is not a copy input without a product decision.
- Grep aid, not a validator, for a polite plural that slipped in: the `-tte` verb ending (`Voitte`, `Haluatte`), `teidän`, `Teidän`, and the plural imperative `-kaa`/`-kää` (`Sallikaa`, `Jatkakaa`, `Muokatkaa`).

## Header and label forms

- Sentence case everywhere in app-owned copy: Finnish capitalises the first word and proper names only. Apple's Finnish does this even in multi-word labels ("Muokkaa Koti-valikkoa", `SpringBoardHome.strings | REARRANGE_ICONS_SHORTCUT_ITEM_TITLE`; "Ilmainen kokeilu", `StoreKit.framework | Localizable.strings | MODE_FREE`; register summary of the 2026-09-16 harvest: sentence case). The 114 Title Case `en` keys lose their inner capitals in `fi` unless the capitalised word is a proper name from `## Platform terms` ("Edit Focus Task" -> "Muokkaa keskittymistehtävää", `focusTask.createTask.screenTitleEdit`; "Total Screen Time" -> "Ruutuaika yhteensä", `profile.appUsage.totalScreenTimeTitle`).
- Eyebrows and stat captions stay uppercase where `en` is uppercase (34 `en` strings have no lower-case letter): MOOD -> MIELIALA, DAY STREAK -> the `streak_term` open decision's form in caps, EST. TIME VALUE -> ARVIOITU AJAN ARVO, TODAY -> TÄNÄÄN, "%@ / HOUR" -> "%@ / TUNTI".
- Uppercasing Finnish is safe and lossless: ä ö å keep their marks (FREE TRIAL -> ILMAINEN KOKEILU, `System/Library/PrivateFrameworks/AppStoreKit.framework | Localizable.strings | INTRO_PRICE_OFFER_FREE_TRIAL`; DESTINATION -> MÄÄRÄNPÄÄ and SAMPLE DATA -> NÄYTEDATA, `System/Library/Messages/iMessageApps/SafetyMonitorMessages.bundle | Localizable.strings | DESTINATION`, `SAMPLE DATA`). Finnish has no dotted/dotless i pair (that is Turkish) and no ß (that is German), so `.textCase(.uppercase)` and `String.uppercased()` need no locale argument for `fi`; the cost of uppercase is width, not correctness (`## Length trigger`).
- Section headers are nominative plural nouns or plural participles agreeing with the listed items: PLANNED / DONE / ANYTIME (`plan.dailyPlan.plannedHeader`, `.doneHeader`, `.anytimeHeader`) -> SUUNNITELLUT / VALMIIT / MILLOIN VAIN; "Recently earned" (`achievements.gallery.recentSection`) -> "Viimeksi ansaitut".
- Tab titles are single nouns (`main.tab.*`): Moneyfesting, Suunnitelma, Tilastot, Profiili.
- Toggles and state labels take the passive past participle or an adjective agreeing in number and case with the labelled noun, never with the reader: "%lld app restricted" -> one "%lld appi estetty", other "%lld appia estetty" (`screenTime.restrictedApps.appsRestricted`); "Focus paused" -> "Keskittyminen keskeytetty" (`widgets.startFocus.paused`); "In progress" -> "Käynnissä" (`widgets.startFocus.inProgress`).

- Status pills that describe the action rather than the reader take the participle alone ("Tallennettu", `common.editor.saved`).

## Numbers, dates, currency and punctuation

Foundation and ICU output below is `fi_FI` on the 2026-09-16 harvest; invisible characters are named.

- Runtime values arrive formatted through `AppLanguage.effectiveLocale` (app `CLAUDE.md:42`), so strings never hard-code an amount or a currency name. Grouping is U+00A0 NO-BREAK SPACE and the decimal mark is a comma: "2 000", "12 000", "1 250,5", "1 250 000". Four-digit numbers are grouped, so "2000" in a literal becomes "2 000" ("2,000 hours of focus", `achievements.badge.wageYear.name` -> "2 000 tuntia keskittymistä").
- Money: `AppCurrency.format` prints "120 €" and "1 250,5 €" with U+00A0 before the symbol, the symbol after the number; the locale's own standard form is "120,00 €". Compact figures print "1,25k €", "1,25m €", "1,25b €", while `fi_FI`'s own compact tokens are "t." (thousand), "milj." (million) and "mrd." (billion): "1,25 t. €", "1,25 milj. €". That is an engineering finding to report, never something to translate around (open decision `compact_currency_suffix`).
- Percent follows the number with U+00A0: "40 %", "100 %". So a badge reads "-56 %", not "-56%".
- Time is 24-hour (`Locale.hourCycle` h23, `DateFormatter` template `j` -> `H`) and the separator is a period, not a colon: "9.41", "23.59". The axis labels `insights.appUsage.axisMidnight`, `axisSixAm`, `axisNoon`, `axisSixPm` and their `profile.appUsage.axis.*` and `screenTimeReport.axis*` twins become "0.00", "6.00", "12.00", "18.00". The widget countdown prints "1.45.00" and "25.00".
- Dates: numeric "31.12.2026"; wide "31. joulukuuta 2026"; weekday "tiistai"; weekday with a numeric day "tiistai 12.5."

Governs the three `en` numeric-range keys and `insights.appUsage.*` axis pairs.
- Quotation marks are ” at both ends (U+201D twice; alternates are ’ ’), which ICU reports for `fi_FI` and Kielitoimiston ohjepankki states: "Suomenkielisessä tekstissä käytettävät kokolainausmerkit ovat kaarevat ”, ja ne ovat samanmuotoiset lainatun jakson alussa ja lopussa" (https://kielitoimistonohjepankki.fi/ohje/lainausmerkit/, fetched 2026-09-16). - Ellipsis follows the source character per key: 9 `en` keys use three periods and 2 use "…"; do not normalise one into the other. Attribution keeps the source's dash (`quote.display.attribution`), and the multiplication sign × stays × ("Keskittymistuntisi × tuntihintasi", `achievements.category.wages.description`).
- Plural categories are `one` and `other` only (ICU 76.1.0.0 / CLDR 46.0.0.0, and Xcode's `variationConfigFile.plist` `PluralRule.ComplementedPluralKeys.fi` lists the same two). `one` is selected by the integer 1 and nothing else; `other` covers 0, 2, 3, 4, 11, 21, 100, 101, 1000, every larger integer, and every fraction tested (0.5, 1.5, 2.5). Exercise 0, 1, 2, 11, 21, 101 and 1000, and note the two traps: 0 is `other`, and 1.5 is `other` although 1 is `one`.
- Numerals attach to nouns in the partitive singular: "Perusmuodossa olevan eli nominatiivimuotoisen lukusanan yhteydessä substantiivi on partitiivimuodossa" (Kielitoimiston ohjepankki, https://kielitoimistonohjepankki.fi/ohje/luvut-ja-numerot-200aa-autoa-vai-200-autoa/, fetched 2026-09-16), which is exactly how Apple's own plural resources split: `one` "%d päivä", `other` "%d päivää" (`System/Library/Health/FeedItemPlugins/Heart.healthplugin | BloodPressureJournal-Localizable.stringsdict | PDF_CLASSIFICATION_COUNT/value/one` and `/other`); `one` "%d minuutti", `other` "%d minuuttia" and `one` "%d tunti", `other` "%d tuntia" (`System/Library/CoreServices/VoiceOverTouch.app | VOTLocalizedStrings.stringsdict | minutes.format/minutes/one`, `/other`, `hours.format/hours/one`, `/other`). Report them as variation additions, not as prose fixes.
- When the counted phrase is not the subject, the numeral and its noun inflect together and the whole phrase changes case ("5 päivän putki", "%lld päivän jälkeen"). A composed string that concatenates a number with a fixed noun fragment cannot follow the sentence into another case, so flag the concatenation and propose one merged key with a format string rather than bending the grammar (`references/agent-protocol.md` `## A. ## Length trigger

- A Finnish string longer than 1.20× its English length goes on the render list (`scripts/catalog_check.py` C5), not into findings. The ratio is measured from Apple's own Finnish translations at iOS 26.1 (23B86), 78,671 English/Finnish pairs from `fi.lproj` of which 45,147 are unique. On the unique, unweighted set 31.0% sit above 1.20× and only 16.9% above 1.35×, so `ro`'s 1.35× would miss half the strings that actually grow; 1.20× is the ratio at which Finnish exceeds as often as Apple's Romanian exceeds 1.35×.
- Across all 78,671 pairs the median is 1.10, p75 1.286, p90 1.545, and 19.4% exceed 1.35×. Short strings expand hardest, which is where this app's controls and captions live: 1-10 characters median 1.2, p90 2.0, 35.1% above 1.35×; 11-20 characters median 1.09; 41-120 characters median 1.046. The 948 all-caps pairs behave the same way (median 1.125, p90 2.0).
- Apple's own pairs, as calibration for a draft: Save -> Tallenna 2.0×, Retry -> Yritä uudelleen 3.0×, Edit -> Muokkaa 1.75×, Done -> Valmis 1.5×, Add Widget -> Lisää widgetti 1.4×, FREE TRIAL -> ILMAINEN KOKEILU 1.6×, Total -> Yhteensä 1.6×, Task -> Tehtävä 1.75×, Focus -> Keskity-tila 2.4×. Finnish also shortens: Continue -> Jatka 0.63×, Screen Time -> Ruutuaika 0.82×, Don't Allow -> Älä salli 0.82×, Got it -> Selvä 0.83×, Cancel -> Kumoa 0.83×, Require Face ID -> Vaadi Face ID 0.87×.
- Counts never establish fit; verdicts come from render evidence against each view's own floor and line limit (`references/surface-budgets.md`, `references/render-evidence.md`). Shortening cuts words, never facts; accessibility strings are exempt.
