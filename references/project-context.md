## Enabling a locale

Snapshot 2026-09-15; re-verify with grep for `supportedLanguageCodes`, `knownRegions` and `CFBundleLocalizations`. Adding target resources does not enable a locale. A language ships only after all of: (1) `AppLanguage.supportedLanguageCodes` (`Manifesting/Foundation/Localization/AppLanguage.swift:6`; gates `overrideCode`, `setOverrideCode`, `preferredQuoteLanguageCode` and the DEBUG `welcomePreviewLanguageCode`); (2) `knownRegions` in `Manifesting.xcodeproj/project.pbxproj` (`en`, `ro`, `Base`) plus the language in `Manifesting/Foundation/Localization/Localizable.xcstrings` and `Manifesting/Foundation/Localization/InfoPlist.xcstrings`; (3) `CFBundleLocalizations` in `Manifesting/ScreenTimeShieldConfigurationExtension/Info.plist` (`en`, `ro`); (4) shield copy: per-language fields on `ShieldMessage` (`titleEnglish`, `titleRomanian`, `bodyEnglish`, `bodyRomanian`, `Manifesting/Foundation/ShieldSupport/ShieldMessage.swift:14-17`), the 25 `ShieldMessageCatalog` values, and the `== "ro"` branches at `Manifesting/Foundation/ShieldSupport/ShieldMessage.swift:20,24` and `Manifesting/Foundation/ShieldSupport/ShieldPresentationCopy.swift:9`, so a third language is a struct change to flag as engineering; (5) `welcome_capture_{block,plan,ring,themes}_<code>.png`; (6) quotes: `SHIP_LANGUAGES` in `scripts/quotes/build_quotes_db.py:47` and a re-emitted bundle, only after the curation decision under Content policy; (7) tests: every literal `["en", "ro"]` array under `ManifestingTests` (18 files at snapshot; grep), while suites iterating `supportedLanguageCodes` pick a new code up on their own.

Regional and script variants: the override stores a bare language code and `locale(forLanguageCode:)` (`Manifesting/Foundation/Localization/AppLanguage.swift:67-74`) rebuilds the locale from that code plus the device region, so pt-BR against pt-PT, or zh-Hans against zh-Hant, cannot be selected in-app. A variant needs an `AppLanguage` change (and its `preferredQuoteLanguageCode` callers), not a translation-only change; flag this before translating any variant, because a full pass the app cannot select is the most expensive waste available. Locale labels against resource tags are decided in `references/locale-decisions.md`.

Findings from the 2026-09-16 locale harvest, each an engineering note rather than translation work. The mirrors already drift from iOS 26.1: the `en` mock alerts use straight quotes where iOS uses curly ones, `onboarding.widgets.howTo.customizeLabel` says "Customise" (Apple's en_GB form) while a US device shows "Customize", and the `ro` mocks say "Nu permite" and "dorește" where iOS ro says "Nu permiteți" and "ar dori" (`references/locale-briefs/ro.md` Open decisions). App Store Connect has no Icelandic and no Bulgarian localization, so those two ship in-app copy under a store listing in another language. Every literal `["en", "ro"]` array under `ManifestingTests` (18 files) and the welcome captures need the new code once a locale is enabled.

## Currency display

Time-value amounts render through `AppCurrency.format` and `formatCompact` with `AppLanguage.effectiveLocale` (device region unless a language override is set): narrow symbol for USD, EUR, JPY and GBP, ISO code otherwise (`Manifesting/Foundation/Localization/AppCurrency.swift:33-36`, `:61`), placement locale-dependent ("1.234,5 RON" in ro, "RON 1,234.5" in en). Never write a currency name such as "lei" into copy: the currency is the user's own choice and independent of the language. Two gaps surfaced on 2026-09-16: `CurrencyCatalog.options` has no CZK, so a Czech device falls back to the suggested USD, and a `bg_BG` device reports BGN, which the list also lacks, even though Bulgaria has used the euro since January 2026. Compact figures append a hardcoded Latin `k`/`m`/`b` (`:53-57`) and reach `Manifesting/Foundation/WidgetSupport/FocusRing/FocusRingCopy.swift:25`, `Manifesting/Foundation/WidgetSupport/MonthlyTimeValue/MonthlyTimeValueTile.swift:53,68`, `Manifesting/Foundation/InsightsSavings/InsightsSavingsCard.swift:36,46`, `Manifesting/Foundation/ScreenTime/ScreenTimeUsageReportViews.swift:126,251` and the insights, celebration, details and session screens. Generate packet sample values with the real formatter; for locales whose compact forms differ (de Tsd./Mio., fr k/M/Md, CJK units, Arabic-Indic digits) report the suffix as an engineering finding, not something to translate around. Visible figures are compact while accessibility labels use the full format: review both. The picker's colloquial search aliases (USA, UK, UAE, Holland; `Manifesting/Foundation/Localization/CurrencyOption.swift:30-36`) are English-only while ICU names are searchable in the locale; local aliases are a code-change proposal, not a translation edit. Storefront prices are a fourth quantity: a live StoreKit `displayPrice` is preserved as rendered, never translated, converted or typed into prose, and today there is none (Subscription row), so no price claim ships while `hasProducts` is false.

## Product and engineering invariants

Moneyfesting links purposeful focus, plans and tasks, aspirations and quotes to the estimated value of the user's time at their own rate. Onboarding and paywall explanations distinguish that value from income, and the app never pays, earns, saves or loses money for anyone. Verify each metric's calculation and each state's behaviour before choosing saved, earned, lost, invested or recovered; keep the aspiration without adding guarantees, guilt, diagnoses or financial advice. The disclaimer has one approved form per locale, recorded in `glossary/<locale>.json`: ro today has "Nu sunt bani câștigați." on ten keys and "Nu reprezintă bani câștigați." on one (`widgets.monthlyTimeValue.description`), so align to the majority rather than adding a third. Figurative source lines (badge names, streak lines, welcome captions) map to the local expression that carries the same meaning and register, never to the image word for word, and back-translation compares the claim, not the picture: "it's pouring" for "plouă cu găleata" is an acceptable adaptation.

Read `Manifesting/Foundation/WidgetSupport/Streak/StreakWidgetCopy.swift` and `Manifesting/Foundation/WidgetSupport/FocusRing/FocusRingCopy.swift` before touching streak or ring copy: freeze coverage is not completed focus, the five-minute streak bar (streak copy lines 36-43 and 136) is not the user's daily goal, and a trailing 30-day value is not today's result. `Manifesting/Foundation/InsightsSavings/InsightsSavingsStrings.swift` separates recorded value, estimates of earlier days and month-end forecasts. Keep these apart in compact labels and in the accessibility explanations, which spell out what the figure means in full sentences.

Copy resolves through `String(localized: LocalizedStringResource(..., locale: AppLanguage.localizationLocale))` behind computed accessors so a language switch applies live; `AppLanguage.effectiveLocale` drives formatting and SwiftUI's locale environment. Keep system-owned widget and intent metadata as deferred resources. Never add manual `.lproj` selection, cached translations, `AppleLanguages` overrides or a relaunch (`CLAUDE.md` "Localization and asset provenance"). App sources have explicit `Manifesting.xcodeproj/project.pbxproj` membership: a new or moved file must stay in both app variants and every consuming extension, and tests belong to both test targets (`CLAUDE.md:25`).

## Content policy

Read `Data/quotes/SCHEMA.md` before touching quote content.

- English quote content is the source of truth and ports to every shipped language (owner decision 2026-09-16). How a record ports depends on its provenance, because attribution and display differ by kind:
  - Authored affirmations and `curated` English-only text carry no attributed speaker: transcreate them as app-authored copy through this skill's protocol, keeping each claim exactly as strong as the English (money and abundance self-talk is allowed content and stays faithful; a quote that ties focusing, blocking apps or using the app to earning money is excluded, per `references/voice-card.md` `## Money frame`), extend `pairId` to the new language for affirmation pairs (it is a curation field: `scripts/quotes/build_quotes_db.py` strips it when emitting the bundle, so nothing in the app reads it), follow the locale brief's gender strategy, and swap the everyday currency noun only where the locale has one (en dollar to ro leu); a locale without one stays currency-free and UI amounts follow the chosen currency.
  - Attributed quotations (`billionaires`, `influential_people`, attributed `stoic`, attributed `motivation`) port only as labelled translations: `Data/quotes/SCHEMA.md` permits translation solely with "an explicit translated-quotation policy and labeling", so a ported record keeps its original text and source, carries a field naming the language it was translated from, and shows the reader that it is a translation. Prefer an existing published translation and cite it. That field and marker are an engineering change to propose; until they ship, an attributed quotation stays in its published language, because a translation displayed as someone's own words misattributes them. In the bundle, `motivation` is almost entirely unattributed `curated` text (384 of 388 English records carry no author, matching `affirmations`'s treatment) with only 4 genuinely attributed records (`supplied_unverified`, "Attributed to Baruch Spinoza"), so treat an unattributed `motivation` record as authored/curated text under the bullet above and reserve this bullet for the attributed remainder, the same distinction already drawn for `stoic`.
  - Scripture (`religion`) joins on `source.canonicalReference` and takes the language's canonical published translation (`Data/quotes/BIBLE_CORPUS.md` is the Romanian pattern), never our own rendering and never a paraphrase.
  - `word_of_the_day` is language-specific: port the format, then choose the word and its `definition` for that language rather than transliterating the English one.
- Port a category completely or not at all. `QuotesRepository.preferredQuotePool` returns only the target-language pool once a category holds any target-language quote (`Manifesting/Features/Quotes/Data/Repositories/QuotesRepository.swift:102-128`), so a dozen ported stoic quotes replace the 965 English ones for that reader instead of adding to them. A language also needs `SHIP_LANGUAGES` (`scripts/quotes/build_quotes_db.py:47`) and a re-emitted bundle before any ported quote reaches the app.
- Preserve quote IDs, favourites, hidden links, author and source metadata and verification distinctions; do not reseed user data to introduce translations. User-created quotes, tasks and names are user content: translate the controls around them only.
- Bundle gate (snapshot 2026-09-15; recount from `Manifesting/Resources/JSONs/quotes.json` before any count claim): 6996 entries, 637 Romanian (600 affirmations, 37 scripture verses) and the rest English (1981 affirmations including the 600 pair originals, 1320 influential_people, 965 stoic, 954 religion, 751 billionaires, 388 motivation). `Data/quotes/quotes-v2.json` also holds sourced quotations in de (79), es (47), it (23), fr (22), nl (12) and a handful of other languages that `scripts/quotes/build_quotes_db.py` withholds via `SHIP_LANGUAGES = {"en", "ro"}` (`:47`), so adding an app language alone changes nothing in quote content. Once shipped, `QuotesRepository.preferredQuotePool` (`Manifesting/Features/Quotes/Data/Repositories/QuotesRepository.swift:102-128`) matches by base language per category and returns only the target-language pool when one exists, so the completeness rule above governs any porting decision; count withheld languages with a read-only pass, never `--emit`. Check the `QuoteMapper` language-propagation note (`Docs/Plans/APP_UPDATE_PLANS.md:46`) before any new quote-content path.
- Badge names (`achievements.*`) share one workplace conceit (`BadgeCopy+Payroll`, `+Shift`, `+Wages`): decide its local equivalent once per locale and keep it across the family, leave plain descriptors plain, prefer gender-neutral forms; earned lines transcreate rhythm but add no facts; criterion lines stay literal.

If the user asks for a policy change, make it precise before generating any attributed or religious material; ordinary UI localization continues independently.
